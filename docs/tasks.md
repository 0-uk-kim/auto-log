# 오토로그 1차(MVP) Subtask 목록

`docs/planning.html`의 1차 개발 범위를 구현 단위로 분해한 목록. 각 항목은 커밋 1~2개 분량이다.

의존 관계: P0 → P1/P2 병렬 → P3 → (P4·P5 병렬) → P6 → P7 → P8
리스크: **#25 Transformer 병합**이 가장 불확실했고, 실기기 계측 테스트로 선검증을 마쳤다.
