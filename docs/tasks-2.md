## 설계 결정

- **자막은 원본을 건드리지 않는다.** 클립 파일은 그대로 두고, 자막(클립 id · 시작 · 끝 · 텍스트)만 Room에 저장한다.
  영상에 새기는 것은 브이로그를 병합할 때 한 번뿐이다 — 자막을 고쳐도 원본을 다시 인코딩하지 않는다.
- **시간은 클립 안의 상대 시각(ms)이다.** 병합할 때 클립마다 효과를 따로 걸면 되므로 전체 타임라인으로 옮겨 적을 필요가 없다.
- **편집 여부 배지는 3차다.** 자막을 달아도 `isEdited`는 아직 켜지 않는다 (planning 5).
